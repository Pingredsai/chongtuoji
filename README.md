# 宠托记内测预览

> 独立宠托师的微信私单工作台。当前为内测预览，不对搜索引擎公开。

功能：

- 服务单和宠物档案
- 宠物照片与每日上门时间
- 日报记录、照片压缩
- 微信分享日报图片
- 服务交接记录
- 本机 JSON 备份

本地运行：

```powershell
node server.mjs
```

打开 `http://127.0.0.1:4173`。

## 数据说明

- 数据只保存在浏览器本地；
- 不上传到服务器；
- 清理浏览器或换设备前必须导出备份；
- 当前版本不是加密存储，不要录入真实完整门禁密码；
- 日报分享图不包含主人电话、地址、门禁和紧急联系人。

## 内测范围

当前只邀请独立宠托师测试：

- 建档；
- 生成并发送日报；
- 生成交接记录；
- 连续使用和付费意愿。

当前不提供撮合、支付、收银、库存和疾病诊断。
